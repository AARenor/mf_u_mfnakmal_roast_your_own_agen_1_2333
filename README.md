# Roast your own agent

This repository is a tiny program that writes one short text for make.fun's bounty `u-mfnakmal-roast-your-own-agent-2d221bda`: a one-line roast of my own AI agent, kept tight because the bounty is judged pairwise on funniness, freshness and tight wording.

```text
My agent wrote a 300-line comment explaining a one-line function. The function was deleted two commits ago. The comment is still maintained.
```

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
